# The unification claim — one statement, with its truth value

**Status:** the operative specification. `docs/orbit-space-unification.md` describes the path;
this document fixes the *claim*, its tiers, and the test ladder. Any job that does not test a
line of this document is off the programme.

## The claim

> **Orbit-space unification.** For a flux compactification, the exact content of the theory is
> exhausted by (i) the duality-invariant constraints, (ii) the topological labels, and (iii) the
> coordinates on the orbit space of vacua under the duality group. There is no fourth kind, and
> in particular no exact relation among the low-energy parameters beyond the constraints.

Stated that way it has a **truth value**, and its three parts are in different states:

| part | statement | state |
|---|---|---|
| **C1** | The invariant ring of the flux pair under `Sp(b₃,ℤ) × SL(2,ℤ)` is generated by the tadpole `N = FᵀJH` alone. | **PROVEN** — Weyl FFT (Constraint-First 5/5), Uniqueness 6/6 + Lean, full-duality 5/5 |
| **C2** | Over ℤ the orbits are classified by `(N, d)` with `d = gcd(F,H)`, `d² | N`, finitely many per tadpole — and `d` carries no physics beyond `W → dW`, `N → d²N`. | **PROVEN** — Completeness 6 exact + 2 numeric; the `d`-physics part by the flux-scaling lemma (5/5 exact + a node numeric control: `|W(2F)|/|W(F)| = 2.0`, tol 1e-10) |
| **C3** | The low-energy data of a vacuum **are coordinates on the orbit space**: the map `orbit → observables` is well-defined (duality-invariant) and locally injective (distinct orbits ⇒ distinct physics). | **CONJECTURED** — this is the part the programme exists to test |
| **C4** | The Standard Model's 19 parameters arise the same way, for the SM's own (unknown) duality structure. | **CONJECTURED, and weaker than C3** — no SM duality group is known, so this is a bet, not a corollary |

**What C1–C2 already forbid.** Not a slogan: an exact polynomial duality-invariant selector for
a vacuum cannot exist. The audit's scope is binding — this says nothing about statistical,
moduli-dependent or non-polynomial selection, and `N ≤ L` *bounds* the search rather than
emptying it.

## What would make C3 false (and this is the point of being precise)

C3 has two halves, and they fail differently:

- **Well-definedness fails** if a duality transformation maps a vacuum to something that is not
  a vacuum, or changes a physical quantity that should be invariant. Test: apply a generator,
  re-evaluate. *This is being tested now* (`scripts/validate_s_duality_vacua.py`: `(F,H)→(−H,F)`,
  `τ→−1/τ`, at fixed moduli, fitting the realised transformation law and its residual).
- **Injectivity fails** if two duality-inequivalent vacua at the same `N` have identical
  low-energy data. Then the "coordinates" are degenerate: the observables under-determine the
  orbit, and there is no dictionary to write — only a many-to-one map.

Both are decidable on samples we already hold. Neither has been tested.

## What would make C4 false

An exact UV relation among the 19 parameters beyond the GUT-style collapses already measured
(gauge 3→1, b–τ 2→1). The rank test measured 19 with those collapses as the only ones; a
relation of any other kind is the falsifier.

## The test ladder, in order — each rung has a fixed falsifier

| # | test | falsifier | cost |
|---|---|---|---|
| 1 | **S-duality on a real vacuum** (`validate_s_duality_vacua.py`) | the realised law scatters (residual in log > 0.10) instead of being a clean function of τ | minutes, node |
| 2 | **Injectivity at fixed N** — cluster duality-inequivalent vacua by `(W₀, g_s)` at fixed N | distinct orbits share identical low-energy data ⇒ C3 false | minutes, corpus, no jaxvacua |
| 3 | **Truncation-independence** — `cond(M)` and the near-null eigenvector across h12 (`diagnose_isd_conditioning.py`) | the invariant structure changes with the truncation ⇒ every frontier number is a slice artefact and C3 is untestable until fixed | 1 node job, running |
| 4 | **The dictionary on one stratum** — write the 19 as functions on one orbit family | freedom beyond GUT's 3 ⇒ C4 false | days, needs 1–3 first |

## What this document deliberately does NOT claim

- It does not claim the SM sector *has* a duality group; C4 is a conjecture.
- It does not claim `m = 9` touches the values; the 19 are still unvalidated as predictions.
- It does not claim the frontier curve is a landscape fact until test 3 lands.
- It does not name a "connecting equation". If C3 holds, the connecting structure is the
  quotient map, and an equation may not exist — which is a *result*, not a gap.
