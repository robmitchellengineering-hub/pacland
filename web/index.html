PACLAND

A probably-approximately-correct verification discipline for the string landscape — what you can claim, what you can measure, and what you cannot compute.
Key results Boundary map Use it GitHub

String theory is ~10500 vacua and no experiment that tells most of them apart. "Unified string theory" fuses two questions — does some vacuum match us? and why that one? — and the field has no verification layer for either. PACLAND is that layer, built with Valiant's probably-approximately-correct learning: a certificate that bounds a candidate's error even when the verifier is itself approximate, a measured prior, a negative result, and a map of the computable.

What we measured

The Mitchell Verification Deficit

m = 5, closing

Started total (m = 0, certificate vacuous). Climbed with real computation: topology h11·h21·c2·κ (m = 4) and the flux tadpole N_flux = FᵀJH exactly (m = 1). SM physics still m = 0.

W₀ prior

log-uniform, R² = 0.92

Measured on 380 SUSY flux vacua (natural measure). The KKLT log-uniform prior — measured, not assumed.

Search over W₀

not evolvable

Log-uniform → zero information → by Valiant's contrapositive, no evolutionary search converges. The search dies; the verifier survives.

Small W₀

43% of vacua

P(|W₀| < 1) ≈ 43% on the natural measure — not the ~5% that biased sampling suggested.

Mass spectrum — no fingerprint

shape random, r < 0.25

On 133 SUSY vacua the mass spectrum's shape (scale-free ratios) is uniform in flux — the long-hoped-for geometric fingerprint is not there. Only its scale is flux-set.

The fingerprint is not in the masses

The field's open hope was that the mass spectrum — the one observable that depends on the full geometry — would be the fingerprint that pins the compactification. We tested it on 133 SUSY flux vacua: the raw eigenvalues are learnable from flux (r = 0.50–0.62, heaviest at z = 5.5), but the scale-invariant ratios — the part that would constitute a fingerprint — are random (r < 0.25). So the spectrum's shape carries no information about the flux; only its overall scale does.

Every flux-determined observable is now measured and uniform: W₀, g_s, gauge couplings, and the mass-spectrum shape. The only learnable structure is the constraint (the tadpole). This is the constraint-first thesis, tested against the one observable that could have broken it — and it held. Paper: fingerprint.pdf.

The Mitchell Verification Deficit — real, and working

The deficit is the count m of observables that are simultaneously measured, computable, and validated. The certificate's oracle term is √(ln 1/δ / 2m), so at m = 0 the certificate is vacuous (infinite radius), and every validated observable shrinks it. It is not a slogan — it is a number we have moved, by building and validating oracles.

The radius fell ∞ → 0.679 in the topology sector as m went 0 → 4, and the flux sector opened at m = 1. Every rung came from a real computation — CYTools on the harness mesh, an exact bilinear fit on 107 real SUSY vacua — never from assumption. That is the significance: the Mitchell Verification Deficit is a working instrument. It reads "vacuous" when there is no verification layer, and it closes one validated oracle at a time as we build that layer.

None of these is undecidable — the landscape problem is an epistemic and underdetermination limit, not a Turing limit. That's itself a finding: the path forward is "build the missing oracles" and "compute the invariants of the underdetermined set," not "invent a faster computer."

Use it

The whole discipline is a pip-installable, pure-stdlib Python library with a CLI:

pip install -e git+https://github.com/robmitchellengineering-hub/pacland.git#egg=pacland
pacland limits                 # the boundary map
pacland certify "flux over W0" # certify a question
pacland mine data.json         # classify observables: structured vs random
pacland constrain data.json    # constraint elimination + uniformity
pacland solve data.json        # constraint-first: the certified viable class
pacland viable data.json       # the viability polytope (the answer is a region)
pacland verify candidate.json  # run guards + falsify against the SM
pacland deficit                # the Mitchell Verification Deficit (m=5, closing)
pacland climb                  # run the deficit climber on the mesh

Full docs: docs/usage.md. The paper: PACLAND-preprint.pdf.

Try the two verification acts

① The certificate (two-level bound)

Bound a candidate's true error even when the verifier is approximate: bound = p̂_g + p̂_e + √(ln 1/δ_s / 2n) + √(ln 1/δ_e / 2m).

Try m = 0 (no validated oracles) and the radius goes infinite — that was the total deficit. Today m = 5: four CYTools topology rungs + the JAXVacua tadpole, all validated by real computation.

② Falsify a candidate

Reality guard α_s(M_Z): target ln = −2.14, tolerance 0.01. A candidate is ruled out iff its prediction is computable and outside tolerance.

verdict:

Non-computable observables rule nothing out — they sit in the prediction zone and are falsifiable later, not now.
